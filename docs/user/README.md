# YYSortを利用する

[文書全体](../README.md) / [コマンド・制御文の全仕様](../../help/help.md) / [実行用サンプル](../../demo/README.md)

配布された実行ファイルを起動します。Windowsは`yysort.exe`、Linuxは`yysort`です。
引数の要約は`--help`、全体の操作仕様は`--manual`でオフライン表示します。

1. 固定長なら`--record-length`とキーのバイト位置・長さを指定する。
2. CSVなら`--format csv`、ヘッダーの有無とキー列を指定する。引用符内の改行・区切りに対応する。
3. `--encoding`と、必要なら出力文字コード・外部対応表を指定する。
4. `--memory`・`--threads`・`--temp-limit`等の上限と、一時領域の空きを確認する。
5. 複雑な変形・複数出力は制御文と`--out NAME=path`を使う。現在の構文はヘルプの表を参照する。

UTF-8以外の文字コード、PD/ZD/BI/FIの数値、同値キーの安定性、出力保全の制限は
[同梱ヘルプ](../../help/help.md)を正とします。対応していないDFSORT指定はエラーです。
作例は入力のコピーで試してください。利用者がソースをビルドする場合は[開発手順](../developer/README.md)へ進みます。
